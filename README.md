## Site structure

```
index.html             Home: name, role, statement, professional positioning, three section buttons
work/index.html        Featured Engineering Tools (one card per tool)
expertise/index.html   Core Technical Domains and Areas of Expertise
skills.html            Technical Skills Tree
css/site.css           Stylesheet for all pages
css/styles.css         Previous stylesheet, kept unchanged for any tool that still links it
fonts/                 Source Serif 4 and Public Sans (SIL Open Font License, see OFL.txt)
js/navigation.js       Mobile menu
```

Each tool lives in its own repository and is served by GitHub Pages at `chetanpatadiya.com/<repository-name>/`. To list a new tool, copy a `project-card` block in `work/index.html` and change its title, badges, description and link.

`/work/` and `/expertise/` are folders so that either section can later move to its own repository under the same address. Old links to `/#work` and `/#expertise` redirect to the new pages.
